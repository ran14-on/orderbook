# Order Book
This is a python matching engine that takes buy and sell orders. It keeps them in an order book, and matches them using priorities of price and time (best price first, the earliest order wins a tie). It handles partial fills. The plan is to build an interface on top of it and then to create a multiplayer market game.

## Disclaimer
This is a game with fake money. It isn't real trading or financial advice
